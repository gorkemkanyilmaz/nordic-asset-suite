## 1. The 2026 App Store Algorithmic Formula & Zero-Dollar Growth Engine

Apple's App Store search ranking algorithm is deterministic and driven by 5 core organic signals:

$$\text{Organic Rank} = f(\text{Keyword Relevance Weight}, \text{Download Velocity}, \text{Search-to-Install CVR}, \text{Rating Volume & Sentiment}, \text{Day 1/7 Retention})$$

### 1.1 Keyword Weight Hierarchy
1. **App Title (30 Characters):** **Highest Weight (10x)**. Exact match here provides the strongest ranking signal.
2. **Subtitle (30 Characters):** **Second Highest Weight (5x)**. Must explain value proposition while housing secondary high-volume keywords.
3. **Keyword Field (100 Characters):** **Direct Index (3x)**. Comma-separated, no spaces, no duplication with Title/Subtitle.
4. **Promoted In-App Purchases (IAP Display Names):** **Search Indexed (2x)**. In-app purchase titles and descriptions appear in search results.
5. **Cross-Localization Indexing (The Multi-Locale Hack):** **300%–400% Extra Free Keyword Real Estate**.

## 5. Organic Review Velocity (The 4.8★ "Delight Moment" Trigger)

Ratings volume directly controls App Store ranking. Apple penalizes apps that spam review prompts on launch.

```swift
// Trigger ONLY after a verified "Delight Moment" using StoreKit 2
import StoreKit

func triggerContextualReviewIfDeserving() {
    let completedDelightActions = UserDefaults.standard.integer(forKey: "delight_actions_count")
    if completedDelightActions >= 3 {
        if let windowScene = UIApplication.shared.connectedScenes.first as? UIWindowScene {
            AppStore.requestReview(in: windowScene)
        }
    }
}
```
